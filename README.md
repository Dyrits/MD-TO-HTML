# MD-TO-HTML

A Markdown to HTML converter made with Python.

## About The Project

A Python static page generator: it walks a `content` directory of Markdown files, converts them to HTML nodes (`converters`), extracts titles (`extractors`), applies a `template.html` and writes the resulting site to a `public` directory, copying static assets along.

### Status

Work in progress (exploratory project).

### Built With

- Python 3 (standard library)

## Getting Started

### Prerequisites

- Python 3

### Running

```sh
python src/main.py    # generates the site from content/ into public/
```
